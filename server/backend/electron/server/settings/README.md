# `settings/` — settings (app agent models, read aloud)

**What lives here:** settings the server itself reads. `agent-models.js`: the models of the internal LLM tasks — env defaults (`CURATOR_MODEL`, `TITLE_MODEL`, `GOAL_CHECK_MODEL`), the key list `AGENT_MODEL_KEYS` with `AGENT_MODEL_DEFAULTS`, the user choice `agentModelSetting` and the model string for `runOnce` (`agentModelFor`, form `provider::model`). The row `agent_model_<key>` (`agentRow`) carries, besides provider+model, the effort LEVEL (`effort`, `agentEffortSetting`; `""` = default, resolved and clamped only in `runOnce` → `effortRunning`); each half may stand alone. Oneshot callers fetch both via `agentRunFor(key)` → `{ model, effort }` — the level travels as its own field, never inside the model reference (which is read as a NAME in several places). Guard: `server/backend/test/oneshot-level.test.js`. `tts.js`: read aloud — `loadTtsConfig` (ElevenLabs key, voice, model, base URL), `plainForSpeech` (Markdown → speech text), `ttsCachePath`.

**Routes (`routes.js`), all in `ROUTES` (`server.js`):** `settingsRoutes` — `/api/ui-lang`, `/api/agent-models` (GET returns `agents`/`defaults` plus `efforts` and `effective` — provider and resolved id that REALLY run; PUT takes `provider`/`model` and `effort` each only when ANNOUNCED, a body with neither is 400), `/api/auto-continue` and `/api/credit-gate` (both switches require the field `enabled`, otherwise 400 — a missing field is not an instruction; switching the gate off wakes the workflow agents waiting at it — `dynworkflows/parking.js:wakeGateWaiting`), `/api/dyn-workflow-cap` (GET `{ cap, preset, max, runCap }` — the per-user cap across all dynamic workflows of this server, default 8, and the per-run cap (fixed 8) for labelling; PUT without `cap` ⇒ 400, integer 1–64, computed in `dynworkflows/cap.js`), `/api/dyn-workflow-size` (GET `{ size, preset, stages }`, small · medium · large · unrestricted, default medium; PUT without or with an unknown `size` ⇒ 400; `dynworkflows/size.js`), `/api/cpu-saver`, `/api/chat-auto-archive`, `/api/agent-hooks`, `/api/permission-rules`, `/api/web-search`, `/api/tts` (`/config`, `/voices`), `/api/playwright-headless`; `adjustRoutes` — `/api/adjust`, `/api/adjust/prompts[/:name]`; `autocompactNotifyRoutes` — `/api/autocompact`, `/api/notify`. **Trap:** `AGENT_MODEL_KEYS` and the catalog in `web/src/components/settings/AgentModelSettings.tsx` are TWO lists — a new key belongs in both, otherwise it cannot be chosen anywhere in the UI.

**What does NOT live here:** the values themselves (`app_settings`, `store/`), the providers' model catalog (`../providers/connectors/claude.js` and `codex.js`, read through the registry `../providers/index.js`) and the provider default (`providers/index.js:defaultModelFor`, passed through `account/providers.js`, which `agentModelFor` falls back to for an empty choice; the default level next to it is `providers/index.js:effortStandard`).

**Terms (→ file):** app agent (title, goal, workflow verdict, compaction, curator, classification, service scan, channel status, adjust) → `agent-models.js` · read aloud, speech text, voice, cache → `tts.js`.

**The three most common questions:**
- Which model and which effort level does a oneshot get (title, target gate …), and why never an empty string? → `agent-models.js:agentRunFor` (model via `agentModelFor`: user choice → default → provider default; level via `agentEffortSetting`). Of the user choice only the PROVIDER is checked (`agentModelSetting`: `isProviderId`) — never the model: a stored id the catalog no longer lists, or that the signed-in account may not run (`visibleModels`), still goes out as `provider::model`. A removed provider falls back to auto, a removed model does not.
- Where is the default per app agent? → `agent-models.js:AGENT_MODEL_DEFAULTS` (nine app agents; the list is bound to web and iOS, `web/test/app-agents-catalog.test.mjs`).
- Why does read aloud answer 409, and how is Markdown reduced before speaking? → `tts.js:loadTtsConfig` (no `apiKey` → system voice in the client) / `tts.js:plainForSpeech`.
