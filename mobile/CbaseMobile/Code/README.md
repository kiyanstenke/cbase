# `CbaseMobile/Code/` — the Coding area except Chat and Workflows

The categories of the Coding tab (`/workspaces` on the web) that `Shell/CategoryContent.swift` switches on, except Chats (`Chat/`) and
Workflows (`Workflows/`, which also holds the dynamic-workflow library `DynWorkflowsPane.swift`, a kind under "Workflows" and no category of its own).

Most pages share one form: a summary line above the list, rows as a tile (`Kit/CbTile.swift`) with a symbol in the color of the situation, no
hairlines, group headers with a small tile, a `CbTileEmpty` row when empty, a detail sheet with a tile header and `ProjectField`, and explanations
behind the ⓘ. Pages that sit on the page background (Code, Terminal, Browser) draw on `CbColor.grund` and separate with `CbHairline` overlays so
the measured size does not change.

**The three most common questions:**
- Where does a file open in the editor? → `CodePane.swift:CodeBrowserModel.open(_:)` loads via `/files/read` and sets `fileState` by text, image, binary or too large.
- Where does terminal output arrive? → `TerminalPane.swift:TerminalSession.listen` reads `client.namedStream("/api/terminal/<id>/stream")` and feeds the ANSI buffer.
- Where is a project entered? → `Models/AppState.swift:enterProject(_:)`, from the pane via `state.enterProject(project)`.
