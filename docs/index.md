# cbase

cbase is a self-hosted, open-source workspace for coding agents. A gateway gives every user their own container with the
agent tools inside; the web app, the desktop client and the iOS app all talk to that server. There is no hosted cbase service:
whoever runs the server decides who uses it and which AI providers it connects to.
